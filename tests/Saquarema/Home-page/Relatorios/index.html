Como interpretar

Cada linha corresponde a um critério, com no máximo uma varredura restrita às regras associadas. Sem regras, o critério fica não avaliado: não há varredura axe, verificação alternativa pelo Playwright ou capturas. As contagens aparecem como “—”, sem indicar aprovação, reprovação ou inaplicabilidade. Mesmo com regras, a cobertura é parcial. Registros históricos não integram esta coleta.
